## Schema validation

`eval::sets::frozen_sets_validate_and_cover_rules` parses every set and:

* rejects duplicate IDs and short sets;
* parses every executable gold as the production `Request`, canonicalizes it
  with the context file and validates it with `opencnpj_query::validate`;
* checks clarify/reject items carry no IR, OOD items are all rejections and
  the intents match the IR operations;
* checks every §7 trap and every SR rule has at least five items;
* validates every dialogue turn and checks the SHA-256 values against the
  dataset card.

The test is part of `cargo test --workspace`.

## Delivery

`opencnpj-insights::render` turns a validated request and its execution
value into the answer envelope (`decision`, `understood`, `blocks`,
`suggestions`, canonical `query`, timing).

* Blocks: text, KPI, comparison, table, chart (bar/line), records,
  company, methodology, sources, caveats, notice, clarify and reject.
* Templates: `crates/opencnpj-insights/templates/pt-BR/answers.toml`, 56
  keys over `(op, metric, shape, turn)`. Variants are chosen by
  `xxh3(encode(canonical IR))`, so wording is stable per question.
* Formatters: pt-BR integer grouping, one-decimal, percent, `month_year`,
  `date`, plural and gender agreement, place and sector labels.
* Caveats are attached by IR feature: C-REG, C-CLOSE, C-DENS, C-CAP,
  C-UNIT, C-SECT, C-PARTIAL, C-MINBASE and C-MEI.
* Suggestions are derived from the operation; caller suggestions and a
  notice override them.

`Payload` separates emitted values from static payloads (`Records`,
`Company`, `Meta`) so list, lookup and meta answers share the same
envelope.

## Acceptance

* **Template lints.** `template_lints_pass` checks that no digit appears
  outside a `{placeholder}`, every placeholder belongs to the renderer
  schema, every supported key has a template and no template key is
  unreachable.
* **Golden snapshots.** `golden_snapshots` renders all 36 golden IR cases
  into `crates/opencnpj-insights/tests/fixtures/answers.json`. The values
  are synthetic execution results (the renderer tests layout and wording,
  not data); national counts were measured in WP-2.3. Regenerate with
  `UPDATE_SNAPSHOTS=1 cargo test -p opencnpj-insights render::tests`.
* **pt-BR format.** `formatters_follow_pt_br` covers thousands
  (`1.234.567`), decimals (`12,3`), percent (`12,3%`), `outubro de 2026`,
  `11/10/2026`, singular/plural and feminine/masculine agreement.
* **No invented numbers.** `no_invented_numbers` walks every rendered
  string (blocks, understood line, suggestions; the canonical query is
  excluded) and checks each numeric token against the result values,
  formatted values, provenance, request and labels. All 36 cases pass.

## Limits and follow-ups

* The snapshots use synthetic values; the renderer is not yet wired to the
  national executor in the CLI. The execution `Value` model is already the
  input.
* `List`, `Lookup` and `Meta` payloads are synthetic until the engine list
  and lookup executors expose rows.
* Compare presentation order uses the canonical member order; the separate
  display order from the interpreter is not carried in the validated IR.
* Template variants are deliberately short; the catalogue of sector display
  names is supplied by `Labels` so the renderer stays I/O-free.
* The uncertain grammar of flow nouns in trends ("passou de 187 para 107
  saldo de registros") is peripheral; a later template pass can split the
  net-registration wording.
